Data Flow

1
User Interaction User updates filters in FilterBar component (Time Period, Warehouse, Category, Status)
↓
2
Shared State Update useFilters composable updates reactive refs (selectedPeriod, selectedLocation, selectedCategory, selectedStatus)
↓
3
View Component Reacts Page components (Dashboard, Inventory, Orders) watch filter changes and trigger API calls
↓
4
API Request api.js builds query params from filters and sends HTTP request to FastAPI backend
↓
5
Backend Processing FastAPI applies filters to in-memory data using apply_filters() function
↓
6
Validation & Response Pydantic validates data models and returns JSON response
↓
7
Component Update Component stores data in reactive refs, computed properties apply additional filtering/sorting
↓
8
UI Render Template renders filtered data with badges, charts, and status indicators

Key Components

Frontend Views (client/src/views/)

  • Dashboard.vue Main overview with key metrics, low stock alerts, and pending orders
  • Inventory.vue Stock level tracking with search, filtering, and detailed item views
  • Orders.vue Order management with status breakdown and delivery tracking
  • Demand.vue Demand forecasts with trend analysis and predictions
  • Spending.vue Financial analytics by category, month, and transaction history

Shared State Management (client/src/composables/)

  • useFilters.js Singleton pattern for global filter state (period, location, category, status)
  • useI18n.js Internationalization with EN/JA support, currency mapping, localStorage persistence
  • useAuth.js Mock authentication with user profile and language-aware data

Backend Core (server/)

  • main.py FastAPI app with all endpoints, Pydantic models, and filter logic
  • mock_data.py Loads JSON data files on startup, exports global data dictionaries
  • data/*.json Source of truth for all application data (7 JSON files)

Filter System

The application uses 4 global filters that apply consistently across all views:

  • Time Period Supports direct months (2025-01) and quarters (Q1-2025, Q2-2025, etc.)
  • Warehouse San Francisco, London, Tokyo
  • Category Circuit Boards, Sensors, Actuators, Controllers, Power Supplies
  • Order Status Delivered, Shipped, Processing, Backordered

Filters are managed by the useFilters composable and synchronized across all components via Vue's reactivity system.
